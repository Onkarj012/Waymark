The failure worth reading

Published page had zero component styling

The report was published as themed body-only HTML, which means the server supplies the stylesheet. The live worker at waymark-api.leo4.dev was built before the visual-plan components existed, so all eleven of them — plan-identity, phase-roadmap, system-flow, dependency-flow, change-map, identity-register, facts, risk-list, verification-board, decision-grid, open-questions — matched no rule and fell back to browser defaults.

The +226 lines of component CSS in theme/theme.css are uncommitted and undeployed. Workers inline the theme at build time, so the fix is a build and deploy, not a markup change.

Two checks that passed and still missed it

A class audit confirmed all 58 class names exist in the local theme.css, and structural validation confirmed the body was well formed. Neither asks the only question that mattered: does the server that will render this actually have the stylesheet? Passing checks are not the same as a looked-at page.
